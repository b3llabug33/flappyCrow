Flappy bird but with a crow !!

## how it works
- space bar makes the crow flap up
- pipes keep spawning and move left at random heights
- fly through the gap between pipes to score a point
- hit a pipe or go off screen and it's game over, with a restart button to try again

## Requirements
- Unity 2022.3.39f1 (or later 2022.3 LTS)

## Running it
1. Clone the repo.
2. Open Unity Hub, click "Add project", and select the `flappy crow/` folder.
3. Let Unity import the assets, then open `Assets/flappycrow.unity` and press Play.
